# 逐線列車玩具造型參考

現行模型採用使用者上傳插畫嘅單卡比例、各線配色及表情。下列車款資料保留作代表車系參考，原有雙卡實車配色方案屬早期版本。[現行模型合照](screenshots/picture-fleet.png)

核對日期：2026-11-18。以下用營運者／製造商／政府公開資料選擇**代表車款**，再以原創點、線、色塊及幾何體繪製。照片、官方商品模型、標誌、商標角色圖形均沒有複製進 app。

Next Train API 不提供實際列車車號或車款。畫面上的某一架位置推算列車，**不能據此辨識它當日真正使用哪款列車**。API 模式及模擬模式使用相同的玩具參考造型，車卡應稱「車款參考」，不能稱「已識別實車」。這不是 2026 年全量車隊清單；若一線使用多款車，選其中一種有來源支持的造型不表示其他車款不存在。

## 視覺與效能

- `apps/web/src/trainProfiles.ts` 保存逐線參考名稱、原創調色與來源 URL；`referenceOnly=true` 是固定語意。
- `TrainModel.ts` 使用三維幾何拼合成兩卡玩具，正 X 為前進方向，Z 向上。車門、玻璃、燈點、腰線、車頭形狀按代表車系區分。車廂數、比例、顏色為玩具改編，不是工程圖或官方色票。
- 頂部小色牌只作路線識別，沿用既有路線視覺色；不改變 `colour_source=osm-unverified`，也不把色牌當實車塗裝。
- 每個模型按顏色合併為最多 8 個 mesh，共用幾何資料；各模型有獨立材質，個別虛擬 trip 淡出不會讓整條線一起變透明。
- `ToyIcon.tsx` 的 `line` 參數使用相同車系輪廓和色塊；省略 `line` 時保留原有原創品牌小火車。
